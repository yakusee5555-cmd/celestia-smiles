# Celestia Smiles — Dental Clinic Website (Demo)

Static single-page dental clinic website: interactive 3D hero tooth, 3D jaw
treatment calculator, services with 3D cards, testimonials with before/after
slider, blog, doctor profile and booking pages. Prices in INR.

Live: https://celestia-smiles.vercel.app

Note: demo site — contact details are placeholders and the patient photos
are AI-generated stand-ins. Swap in the clinic's real photos and contact
details before using it for a real clinic.
